# Folder: Data Visualisations with Tableau

## Hollywood Film Performance Analysis (2007–2011)

### Project Overview

This project explores the performance of Hollywood films released between 2007 and 2011 using exploratory data analysis and data visualisation.

The objective was to investigate relationships and differences between film studios, genres, profitability, worldwide gross and audience ratings.

Using **Tableau Public**, I developed interactive dashboards to explore the dataset, identify patterns and communicate meaningful findings through visualisations.

### Project Objectives

The main objectives of this project were to:

- Explore the distribution of films across different genres and lead studios.
- Compare the average profitability of films produced by different studios.
- Investigate worldwide gross across studios and genres.
- Examine the relationship between audience ratings and critics' ratings.
- Explore patterns in film performance over the 2007–2011 period.
- Develop interactive Tableau dashboards to communicate analytical findings.

### Dataset

The dataset used in this project is **Hollywood's Most Profitable Stories**, obtained from Kaggle.

- **Dataset:** [Hollywood's Most Profitable Stories](https://www.kaggle.com/datasets/brendan45774/hollywood-most-profitable-stories)
- **Author:** Brendan45774
- **Coverage:** Hollywood films released between 2007 and 2011.
- **Records:** 74 films.
- **Features:** Film title, genre, lead studio, audience score, profitability, Rotten Tomatoes score, worldwide gross and release year.

The dataset contains information about film performance, studio representation, audience reception and critical reception.

### Dashboards and Visualisations

The project is organised into two dashboards, each focusing on a different aspect of film performance.

#### 1. Hollywood Film Performance Dashboard

This dashboard examines how films associated with different lead studios perform.

The visualisations explore:

- Number of films represented by each studio.
- Average profitability by studio.
- Worldwide gross by studio.

#### 2. Genre and Film Performance Dashboard

This dashboard explores differences in performance across film genres and individual films.

The visualisations explore:

- Audience ratings of films across different genres.
- Genre and individual film performance.
- Average profitability across genres.

### Key Findings

The analysis produced several observations:

- Independent films had the largest representation in the dataset, with 19 films, followed by Warner Bros. with 12.
- Disney recorded the highest average profitability among the studios represented, at approximately 7.41.
- Independent films recorded the second-highest average profitability, at approximately 6.58.
- Disney also recorded the highest average worldwide gross, at approximately 288.66.
- Warner Bros. recorded the highest combined worldwide gross, at approximately 2,081.19.

These findings demonstrate that studio representation, average profitability and total worldwide gross can produce different conclusions when comparing studio performance.

### Limitations

The findings are based solely on the available dataset and should not be generalised to the entire film industry.

There are several limitations to consider when interpreting the analysis:

- **Dataset size:** The dataset contains only 74 films, which limits how broadly the findings can be generalised.
- **Time period:** The analysis covers films released between 2007 and 2011 and does not represent current film industry performance.
- **Missing values:** Some records contain missing information, which may affect certain calculations and comparisons.
- **Studio representation:** The number of films varies considerably between studios, meaning some average values are based on relatively small samples.
- **Scope of analysis:** The project focuses on the variables available in the dataset. Other factors that may influence film performance are not included.
